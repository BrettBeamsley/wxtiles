# WxTiles Workspace Rules & References

This workspace is a modernized rebuild of the public WxTiles Leaflet demo.

- **Primary Reference Documentation**: [WxTiles Leaflet Docs](https://metoceanapi.github.io/wxtiles-leaflet/docs)
- **Local Dev Server**: Static HTML/JS. Serve via `python -m http.server 8080` or similar static server.
- **Key Files**:
  - `index.html`: Main Leaflet map view
  - `main.js`: Layer loading and WxTiles controls
  - `styles.css`: Responsive map UI styles
